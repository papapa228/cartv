# BMW Flow Launcher

Домашний экран для QDIS AirTouch PERFORMANCE 8x (Android 8.1, 1600×600). Root не требуется.

## Где взять APK

GitHub Actions собирает APK после каждого изменения в ветке `main` и публикует его в **Releases**.
Последняя версия всегда доступна по ссылке:
https://github.com/papapa228/cartv/releases/latest/download/BMWFlow.apk

Номер версии равен номеру сборки (1.0.N), поэтому каждая новая сборка новее предыдущей.

### Ключ подписи

Все версии подписываются одним ключом, иначе Android не даст поставить обновление поверх.
Ключ хранится в репозитории только в зашифрованном виде (`app/release.keystore.enc`).
Пароль лежит в секрете GitHub `KEYSTORE_PASSWORD` (Settings → Secrets and variables → Actions).
Без этого секрета сборка остановится с понятной ошибкой. Сохраните пароль отдельно: если ключ потерять, обновлять поверх уже не получится.

## Автообновление

- Лаунчер проверяет новую версию примерно через 8 секунд после открытия главного экрана, при появлении интернета и не чаще раза в 6 часов.
- Если версия новее, появляется окно «Обновление BMW Flow» с номером версии и описанием изменений, с кнопками **Обновить** и **Позже**. «Позже» откладывает напоминание на 6 часов.
- APK скачивается с полосой прогресса и передаётся на установку. Без root Android всегда показывает системное окно «Установить», его нужно подтвердить. После установки лаунчер перезапускается уже новой версией.
- При первом обновлении Android попросит разрешить BMW Flow устанавливать приложения. Включите разрешение и нажмите «Назад», загрузка продолжится сама.
- Проверить вручную: удерживайте часы 3 секунды и выберите «Проверить обновления».

## Установка через USB

1. Скопируйте `BMWFlow.apk` в корень флэшки (FAT32 или exFAT) и вставьте её в USB-разъём приставки.
2. На приставке откройте файловый менеджер, найдите на флэшке `BMWFlow.apk` и нажмите на него.
3. Если Android спросит про установку из неизвестных источников, разрешите её для файлового менеджера и вернитесь к установке.
4. Нажмите «Установить».
5. При первом запуске лаунчер запросит доступ к местоположению. Он нужен только для погоды. Без него всё остальное работает, а город можно указать вручную.

## Как сделать BMW Flow домашним экраном

1. Нажмите кнопку «Домой» на приставке. Android предложит выбрать приложение для главного экрана.
2. Выберите **BMW Flow** и нажмите **«Всегда»**.

Если окно выбора не появилось, откройте Настройки → Приложения → Приложения по умолчанию → Главный экран и выберите там BMW Flow. На некоторых прошивках этот пункт находится в Настройки → Приложения → ⋮ → Приложения по умолчанию.

Штатные компоненты AirTouch не удаляются и не отключаются.

## Как вернуть штатный лаунчер

- **Через BMW Flow:** удерживайте часы 3 секунды, откройте «Выбрать домашний экран Android» и выберите штатный лаунчер.
- **Через Android:** Настройки → Приложения → Приложения по умолчанию → Главный экран.
- **Радикально:** удалите BMW Flow. Android сам вернётся к штатному лаунчеру.

## Скрытые настройки

Чтобы открыть, удерживайте часы на главном экране 3 секунды. Доступно:

- переназначение любой из плиток 1–7 на другое приложение (или возврат к автоопределению);
- выбор города для погоды вручную, если геолокация недоступна;
- принудительная синхронизация времени по NTP и её текущий статус;
- переход к выбору домашнего экрана Android.

При первом запуске лаунчер сам ищет нужные приложения: сначала по известным именам пакетов, затем по названию на приставке. Например, «ЧимаТВ» находится по названию, начинающемуся с «Чима». Если плитка показывает знак вопроса, назначьте приложение вручную.

## Часы и погода

- **Время.** При появлении интернета лаунчер получает точное время по NTP и дальше считает его от внутреннего таймера. Поэтому сброс системных часов после выключения автомобиля не влияет на часы лаунчера. Системное время Android не изменяется. Значок часов в правом верхнем углу горит ярко, когда время синхронизировано.
- **HTTPS при неверных системных часах.** Сертификаты проверяются полностью. Если системная проверка не прошла только из-за даты, цепочка проверяется повторно теми же корневыми сертификатами Android, но на точную дату из NTP. Проверка TLS не отключается.
- **Погода.** Прогноз берётся из Open-Meteo (ключ не нужен) на три дня и обновляется примерно раз в 30 минут, пока главный экран открыт или при возврате на него. Последний успешный прогноз сохраняется и показывается без интернета.
- **Источник координат** выбирается по порядку: город, заданный вручную → последнее известное местоположение (GPS или сеть, в том числе полученное навигатором) → однократный запрос координат → последние сохранённые координаты.

## Замена фона

Сейчас вместо фона стоит тёмная заглушка `app/src/main/res/drawable/background.xml`. Чтобы поставить фото:

1. Удалите `app/src/main/res/drawable/background.xml`.
2. Положите изображение как `app/src/main/res/drawable-nodpi/background.jpg`, примерно 860×600 px. Автомобиль должен быть слева, правый край картинки уходит под плавное затемнение.
3. Отправьте изменения в `main`: GitHub соберёт новый APK.

- [ ] Интерфейс без обрезки на 1600×600
- [ ] Все восемь плиток открывают нужные приложения
- [ ] Кнопка «Домой» возвращает в BMW Flow
- [ ] «Все остальные» показывает остальные приложения, кнопка «BMW Flow» возвращает назад
- [ ] Погода по геолокации; с отключённым GPS — по сети или выбранному городу
- [ ] Прогноз остаётся на экране после отключения интернета
- [ ] Часы правильные после полного выключения автомобиля (после появления интернета)
- [ ] Лаунчер открывается при переходе BMW → Android
- [ ] Лаунчер работает после выключения и повторного включения питания

## Структура проекта

| Файл | Назначение |
|---|---|
| `MainActivity.kt` | Главный экран: часы, погода, восемь плиток, полноэкранный режим |
| `AllAppsActivity.kt` | Экран «Все остальные» |
| `SettingsActivity.kt` | Скрытые настройки |
| `TrustedClock.kt` | NTP-клиент и независимые часы лаунчера |
| `Http.kt` | OkHttp с проверкой сертификатов по точному времени |
| `Weather.kt` | Open-Meteo, кэш прогноза, геолокация |
| `Apps.kt` | Описание плиток, поиск и запуск приложений |
| `Ui.kt` | Масштабирование под 1600×600, оформление плиток |
